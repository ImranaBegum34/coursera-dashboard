Coursera Course Analytics Dashboard

A simple and clean Power BI dashboard analyzing Coursera courses dataset.

📊 Overview

This dashboard provides insights into Coursera courses, including:

Total number of courses

Average course rating

Total number of reviews

Distribution of courses by difficulty level

Top course providers

Course rating distribution

It is built using Microsoft Power BI Desktop with a dataset downloaded from Kaggle.

🗂 Dataset

Source: Kaggle (Downloaded locally)

Format: CSV

Columns used:

Course Title

Rating

Level

Instructor

Offered By

Duration to complete (Approx.)

Number of Review

No location or country data available.

📌 Dashboard Layout

Top Row – KPI Cards:

Total Courses

Average Rating

Total Reviews

Middle Row – Charts:

Courses by Level (Column Chart)

Top Providers (Treemap / Donut Chart)

Bottom Row – Optional Chart:

Course Rating Distribution (Column Chart)

Styling:

Simple, clean layout without additional backgrounds

Default colors and readable font sizes
